# Campus Notes Lending System (CNLS)

A web-based lending system that allows university students to lend and borrow printed academic lecture notes from each other.

## Project Overview

The Campus Notes Lending System was developed using PHP and MySQL in a XAMPP environment.

The application manages students, academic notes and lending transactions through a relational database and provides search, filtering, validation and explainability features.

## Key Features

- Create, read, update and delete (CRUD) operations
- Academic note listing and management
- Note lending and return processes
- Search by note title and course name
- Department and availability filters
- Server-side validation
- Prepared statements for database operations
- Late-return penalty calculation
- Explainability panels showing active filters, validation rules and penalty calculations

## Database Structure

The relational database consists of three main entities:

- Members
- Notes
- Loans

The database structure was designed with relational integrity and normalization principles.
